Entry for the [Funniest One-Line Out-of-Office Reply](https://make.fun/c/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) bounty on make.fun ($2, top 3).

## The entry

> I'm away until Monday. Dave is covering for me. Dave has been on holiday since Tuesday.

## How it works

`main.py` is a deterministic, stdlib-only Python 3.13 program (no network).
It writes the single out-of-office line above to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), after
validating it against the competition gate: 1–160 characters, one line,
no control characters or tabs.

```sh
python3 main.py
```
